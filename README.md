# FastAPI Local Offline AI Service

This example demonstrates a simple, local, and offline AI service using FastAPI. It simulates a core component of the "Offline AI Coding Studio" concept, where AI processing happens entirely on the user's machine without relying on cloud services. The example includes a basic rule-based sentiment analysis function for Turkish text, exposed via a local API endpoint.

## Language

`python`

## How to Run

1. Install FastAPI and Uvicorn: `pip install fastapi uvicorn`
2. Save the code as `main.py` and run: `python main.py`
3. Open your browser to `http://127.0.0.1:8000/docs` to interact with the API.
